# HRM System (MERN)
Requirements: Node 16+, npm 8+, MongoDB running locally.

    cd server && npm install && cp .env.example .env && npm run seed && npm run dev
    cd client && npm install && npm run dev      # http://localhost:5173

Demo logins (password Pass@123): hr@hrm.com, mgr@hrm.com, emp@hrm.com
New sign-ups are always employees; HR promotes people to manager and assigns teams on the Employees page.
